# markitdown-go

Go module `github.com/godwit-email/markitdown-go`. It extracts text from attachment bytes.

```sh
CGO_ENABLED=0 go test -count=1 -timeout 180s .
```

The tests read samples from `packages/markitdown/tests/test_files/`, `packages/markitdown-ocr/tests/ocr_test_data/`, and `packages/markitdown-sample-plugin/tests/test_files/`.
